# Local PDF Sample Corpus

Place technical PDFs (datasheets, Technical Reference Manuals, errata, application notes) in this directory for local conversion and benchmarking.

All `*.pdf` files in `samples/` are gitignored to keep repository clones lightweight.

## Current Local Fixtures

- `mspm0c1105_datasheet.pdf` — TI MSPM0C1105 / MSPM0C1106 Mixed-Signal Microcontrollers Datasheet (Rev. B, 138 pages)
- `mspm0c1105_trm.pdf` — TI MSPM0 C-Series 24-MHz Microcontrollers Technical Reference Manual (Rev. C, 1,313 pages)
